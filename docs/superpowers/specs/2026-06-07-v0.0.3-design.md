# v0.0.3 设计规格

日期: 2026-06-07

## 概述

Lumiracle 博客 v0.0.3 版本，四项变更：页面切换动画、时光回廊改为相册、文章归档迁移至关于页、关于页重构。

## 1. 页面切换动画 — 星尘消散

### 1.1 动画流程

路由变化时触发三阶段动画：

1. **退出**（0.3s）：当前页面内容 opacity → 0 + translateY(-8px)，同时从页面中心生成 30-40 个星尘粒子向外扩散
2. **过渡**（0.2s）：星尘粒子继续飘散渐隐
3. **进入**（0.3s）：新页面 translateY(8px) → 0 + opacity 0 → 1

总时长约 0.5s。

### 1.2 技术实现

- 使用 `motion/react` 的 `AnimatePresence` + `m.div`
- `PageTransition` 组件包裹 `{children}`，监听 `usePathname()` 变化触发动画
- 星尘粒子使用绝对定位的 `m.div` 元素（非 Canvas），每个粒子随机方向、大小（2-4px）、颜色（accent 色系）
- 粒子数量：30 个，从视口中心向随机方向扩散 80-200px，生命周期 0.5s
- 尊重 `prefers-reduced-motion`：禁用时退化为简单 opacity 淡入淡出（0.2s）

### 1.3 文件变更

- `src/components/PageTransition.tsx` — 重写

## 2. 时光回廊 → 瀑布流相册

### 2.1 核心变更

完全替换原有文章归档功能，变为纯图片展示页面。不再展示任何文章信息。

### 2.2 数据源

新建 `data/gallery.yml`，每条记录包含：

```yaml
- url: https://example.r2.dev/sunset.jpg
  title: 夕阳
  date: 2026-05-28
```

字段说明：
- `url`（必填）：图片远程地址，任意来源
- `title`（必填）：图片标题
- `date`（可选）：日期，用于排序，格式 YYYY-MM-DD

构建时通过 `lib/gallery.ts` 读取并解析该文件，按 date 倒序排列。

### 2.3 页面布局

- **顶部**：保留"时光回廊"标题区（渐变背景 + 标签），图标从 Archive 改为 Camera
- **内容区**：CSS `columns` 瀑布流布局
  - 移动端：2 列
  - 桌面端：3 列
  - 列间距：12px
- **图片卡片**：
  - 圆角 8px，边框 `border-border`
  - hover：上浮 2px + 发光阴影 `0 0 12px var(--glow)`
  - 图片下方显示标题（12px，accent 色）和日期（10px，muted 色）
  - 使用 `next/image` 的 `unoptimized` 模式（远程图片，静态导出无法优化）
- **Lightbox**：点击图片放大查看，背景遮罩 + 居中大图，点击遮罩或按 Esc 关闭
- **底部**：显示图片总数

### 2.4 导航更新

`site-config.ts` 中"时光回廊"标签保持，图标从 `Archive` 改为 `Camera`（lucide-react）。

### 2.5 文件变更

- `src/app/archive/page.tsx` — 重写
- `src/lib/gallery.ts` — 新建
- `data/gallery.yml` — 新建
- `src/lib/site-config.ts` — 修改图标

## 3. 文章归档迁移至关于页

### 3.1 归档区域

从原有归档页提取文章列表功能，缩小后嵌入关于页：

- 紧凑列表：年份标题 + 每行一条（标题 + 日期）
- 无时间线光束、无描述、无分类标签
- 年份标题：14px，accent 色，font-weight 700
- 文章行：flex 布局，标题左对齐 + 日期右对齐，12px
- 点击标题跳转到文章页
- 使用 `getPostsGroupedByYear()` 复用现有数据逻辑

### 3.2 文件变更

- `src/app/about/page.tsx` — 重写（含归档区域）

## 4. 关于页重构 — 纵向流式

### 4.1 布局结构

```
┌─────────────────────────────────┐
│         ✦ 守护者之室             │
│                                 │
│           [头像圆]               │
│          Lumiracle              │
│     收集灵光与碎片，编织成       │
│       记忆的星河                 │
│                                 │
│     [✉ Email]  [◈ GitHub]      │
│                                 │
│  ───── ✦ ───── (魔法分隔线)     │
```

### 4.2 组件细节

- **头像区**：居中，64px 圆形，渐变背景 + ✦ 符号，发光阴影
- **名称**：18px，accent 色，font-weight 700
- **简介**：11-12px，muted 色，居中
- **联系方式**：胶囊按钮行，flex 居中，gap 12px，边框 border-border，hover 变 accent
- **魔法分隔线**：复用 `MagicDivider` 组件
- **归档区**：见 3.1 节
- 整体 `max-w-2xl mx-auto`，保持窄屏阅读感

- `src/app/about/AboutContent.tsx` — 可删除（当前为空文件）

## 5. 技术约束

- Next.js 16 App Router，静态导出（`output: 'export'`）
- Tailwind CSS v4 语法
- motion/react（LazyMotion + domAnimation）
- 远程图片使用 `next/image` 的 `unoptimized` 属性
- 所有动画尊重 `prefers-reduced-motion`
- YAML 解析使用 Node.js 内置或轻量库（如 gray-matter 已安装，可复用其 YAML 解析）
